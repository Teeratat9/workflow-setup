ลำดับการฝึก 4 ขั้น

ข้อผิดพลาดที่คนส่วนใหญ่ทำคือกระโดดไปขั้น 3 เลยแล้วล้มเลิกใน 2 สัปดาห์ ทำตามลำดับ แล้วอย่าข้าม — แต่ละขั้นสร้างกล้ามเนื้อความจำที่ขั้นถัดไปต้องใช้

  1. ห้ามใช้ปุ่มลูกศร

    สัปดาห์ที่ 1 — อย่างอื่นยังไม่ต้องสนใจ

    บังคับตัวเองใช้ h j k l อย่างเดียว และเพิ่ม w b (ข้ามคำ) 0 $ (หัว/ท้ายบรรทัด) gg G (หัว/ท้ายไฟล์)

    ช่วงนี้คุณจะช้าลงกว่า VS Code มาก — นั่นปกติและจำเป็น อย่าเพิ่งเอา Neovim ไปทำงานที่มี deadline

  2. เริ่มประกอบ verb + motion

    สัปดาห์ที่ 2–3

    เอาตารางไวยากรณ์ด้านบนมาใช้จริง เริ่มที่ ciw ci" ci{ แล้วค่อยเติม da( yi[

    กฎข้อเดียว: เวลาจะแก้อะไร หยุดคิดสักวินาทีว่า "มี motion ที่ตรงกับสิ่งที่ตาเห็นไหม" ก่อนจะกด x รัว ๆ

  3. ใช้ LSP แทนการอ่านโค้ดด้วยตา

    เดือนที่ 2 — ตรงนี้เริ่มเร็วกว่า VS Code

    gd เข้าไปดู แล้ว Ctrl o เด้งกลับ ทำวนแบบนี้จนเป็นนิสัย มันคือวิธีอ่าน codebase ที่ไม่รู้จัก

    เลิกแก้ import ด้วยมือ — ใช้ Space c a กับ Space c M แทน

  4. ปรับ config ตามที่เจ็บจริง

    เดือนที่ 3 เป็นต้นไป

    อย่าแต่ง config ก่อนถึงขั้นนี้ — คุณจะไม่รู้ว่าอะไรควรแก้ เมื่อเจออะไรที่ขัดใจซ้ำ ๆ ค่อยเพิ่มไฟล์ใน ~/workflow-setup/nvim/lua/plugins/

    อยากได้ภาษาเพิ่ม (Dart/Flutter, Go, Rust) ใช้ :LazyExtras เลือกแล้วกด x — ไม่ต้องเขียน config เอง

ข้อควรรู้เฉพาะเครื่องนี้

สามเรื่องนี้ต่างจาก tutorial ทั่วไปในเน็ต ถ้าไม่รู้จะงงว่าทำไมทำตามแล้วไม่ตรง

1 · ไม่ได้ใช้ Telescope และ neo-tree

LazyVim 16 เปลี่ยนมาใช้ snacks.nvim เป็นทั้ง picker และ explorer แล้ว บทความเก่า ๆ ที่สอน :Telescope find_files หรือ :Neotree จะใช้ไม่ได้ — แต่ keymap อย่าง Space f f ยังเหมือนเดิม เพราะ LazyVim รักษา keymap ไว้แม้เปลี่ยน plugin ข้างใน

2 · Python LSP ไม่ได้ลงผ่าน Mason

pyenv global ของคุณชี้ไปที่ Python 3.5.10 ซึ่ง EOL ตั้งแต่ปี 2020 และเก่าเกินกว่าที่ basedpyright รองรับ Mason จึงติดตั้งไม่สำเร็จ

ทางแก้ที่ใช้คือ uv tool install basedpyright ซึ่ง uv พก Python ของตัวเองมา ไม่แตะ pyenv เลย แล้วบอก LazyVim ด้วย basedpyright = { mason = false } ใน lua/plugins/python.lua

3 · Completion คือ blink.cmp ไม่ใช่ nvim-cmp

Tab เลื่อนตัวเลือก Enter ยืนยัน Ctrl Space เรียกเมนูขึ้นมาเอง ถ้าไปก๊อป config nvim-cmp จากเน็ตมาใส่ มันจะไม่ทำงาน (config เดิมของคุณเป็นแบบนั้นพอดี)

Render: mermaid, HTML, markdown
